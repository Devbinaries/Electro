# Electro
Source files for the compssa 2026 hackathon project

**First things first**:
Clone the repository.

```git
git clone "https:github.com/DevBinaries/Demo-Elect.git"
```

**Open in VS Code:**
```bash
cd  src/Demo-Elect
code .
```
📝: replace src with the folder directory in which this repo was cloned


###Project Runtime Environments
* Node js
* Python 

### Version Control
* Git
* GitHub

####Installing Dependencies 
```python
cd core 
pip install -r requirements.txt
```
**If you've installed pipenv:**
```python
cd core 
pipenv install 
```

```node
npm install 
```

####Running The Development Server
**The Django Project:**
```python
python manage.py runserver 
```
** The React Project **
```node
npm run dev
```
